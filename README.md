🎯 Quiz Game

A simple and interactive quiz game to test your knowledge with fun questions! 🧠✨

📌 About the Project

This is a web-based quiz game built using HTML, CSS, and JavaScript.
It presents users with multiple-choice questions and provides instant feedback based on their answers.

🚀 Features

📝 Multiple-choice questions
⏱️ Instant answer feedback
📊 Score tracking
🎨 Clean and responsive UI
🔁 Restart quiz option

🛠️ Technologies Used

HTML
CSS
JavaScript
